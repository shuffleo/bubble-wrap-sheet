# Material and library provenance

## User-supplied photography

The texture source is a 1500 x 1500 pixel image included at `assets/source-reference.jpg` so the crop audit and atlas are reproducible. The full source is also shown inside the explicitly labeled crop inspector, not used as a static background behind invisible hit boxes.

The first, visibly watermarked reference is not embedded. No watermark was removed. The latest blue cut-edge reference is not packaged, sampled, or used as a texture; only its irregular-cut logic informed the procedural boundary.

There are 64 explicitly reviewed source ellipses. Sampling stays inside each ellipse, including image-space variant distortions; measured maximum normalized source radius is 0.9992783189658444. The surrounding tile extends the seal inward rather than sampling an adjacent dome. This numerical containment does not establish automatic semantic segmentation; the footprints were manually positioned and visually checked.

Both atlases are grayscale 2560 x 2048 JPEGs, 20 columns x 16 rows of 128-pixel cells. Each has 320 unique generated cells. Inflated variants use small interior warps and tonal differences, without arbitrary rotation of baked light. Collapsed variants remove broad dome shading and combine photographic high-frequency detail with generated folds. They are not separately photographed popped bubbles, and they are not AI-generated images.

The manifests and source-review images are generated together by `scripts/build_atlas.py`. Edit that script's PATCHES array to change the source map. Do not silently replace the source image without rebuilding its footprint map.

The source photograph's ownership and licensing have not been independently verified. This archive is for the user's prototype review. Obtain appropriate rights or replace it with cleared photography before public/commercial redistribution. No license for the original image is asserted.

## Code libraries

- `vendor/bootstrap-5.3.6.bundle.min.js`: existing locally available Bootstrap 5.3.6 bundle, actually used for the Offcanvas sidebar. Its upstream MIT header is preserved, with a full notice in `licenses/Bootstrap-MIT.txt`. Styling is project-specific.
- `bubble-blend.ts`: selected Soft Light, Darken and Overlay scalar functions vendored/adapted from Jamie Owen's `glsl-blend`. Full MIT notice is in `licenses/glsl-blend-MIT.txt`. The other separable blend formulas and dispatch code are included directly.
- Bootstrap reference: https://getbootstrap.com/docs/5.3/components/offcanvas/
- Shader reference: https://github.com/jamieowen/glsl-blend

## Audio and supplied defaults

See AUDIO-NOTES.md for the Anthousai / Freesound / CC0 attribution supplied by the user. The three original pop WAVs and original refresh WAV are now included in assets/audio/original; their processed outputs are included separately and embedded in the app. Generated test fixtures are clearly labeled and are not used as the default sound bank. The standalone fallback/crinkle synthesis is separate project code.

`presets/uploaded-preset.json` is the user-provided version-3 preset. Material/grading values are preserved. The current explicit size request overrides `bubbleSize: 100` to **52 (S)**. The restored Original motion profile overrides the faster pressure/collapse values, as documented in MOTION-CHANGES.md. Seed values are placeholders: startup and refresh regenerate both. `showHandles: true` enables invisible grab targets, not painted markers. New keyboard and sampled-audio controls are additive.

## Favicon and sharing assets

The icons and two social cards in assets/icons and assets/social are generated by scripts/make_social_assets.py from the actual WebGL renderer. The single-bubble surface supplies the favicon. Social text uses system-installed Liberation Sans (or DejaVu fallback); no font files are included. The photograph source licensing caveat above also applies to these derived visual assets.
